# Online Store System

![Java](https://img.shields.io/badge/Java-17-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## Description

A simple online store management system built with Java,
demonstrating OOP principles, custom exceptions, and
interactive CLI interface.

## Features

- Add products with stock and price
- Register customers
- Shopping cart management
- Place and track orders
- Order status transitions
- Custom exception handling
- Interactive menu with switch

## Technologies

- Java 17+
- OOP (Inheritance, Polymorphism, Encapsulation)
- Custom Exceptions
- Enum, Record
- Collections (List)
- Switch statements
